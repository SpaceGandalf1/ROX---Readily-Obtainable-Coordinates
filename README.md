# Rox
A Gmod Addon for making "getpos" easier. Especially when used multiple times. 

## Installation:
The file should look like this: "C:\Program Files (x86)\Steam\steamapps\common\GarrysMod\garrysmod\addons\Rox\lua\entities\rox_marker.lua"
Drag the "Rox" folder into your addons folder. That's all.
